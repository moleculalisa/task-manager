# Task Manager API
Минимальный REST API для создания и получения задач.

### Возможности
- создание задачи;
- получение задачи по ID;
- валидация данных;
- документирование API в Swagger UI;
- описание моделей данных и ошибок.

### Технологии
- Python 3.12
- FastAPI
- Pydantic

### Установка
Создать виртуальное окружение:
python3 -m venv .venv

Активировать виртуальное окружение:
source .venv/bin/activate

Установить FastAPI:
pip install fastapi

### Запуск
Запустить приложение командой:
python -m fastapi dev main.py

После запуска API доступен по адресу:
http://127.0.0.1:8000

Swagger UI
Интерактивная документация API доступна по адресу:
http://127.0.0.1:8000/docs
В Swagger UI можно проверить работу эндпоинтов, моделей данных, валидации и ошибок.
API
POST /tasks
Создаёт новую задачу.
Параметры запроса:
- title — название задачи от 3 до 100 символов;
- description — необязательное описание задачи;
- priority — приоритет задачи от 1 до 5.

При успешном создании возвращается созданная задача с уникальным идентификатором.
Код ответа: 201 Created.

GET /tasks/{task_id}
Возвращает задачу по её уникальному идентификатору.
Если задача с указанным идентификатором не найдена, возвращается ошибка 404.
Код ответа: 200 OK.

### Валидация
Для данных задачи установлены следующие ограничения:
- title — от 3 до 100 символов;
- description — необязательное поле;
- priority — целое число от 1 до 5.
При передаче некорректных данных API возвращает ошибку 422.

### Ошибки
- 404 Not Found — задача с указанным идентификатором не найдена.
- 422 Unprocessable Entity — переданы некорректные данные или параметры.
Хранение данных
Задачи хранятся в памяти приложения в словаре.
После перезапуска приложения созданные задачи удаляются.

## Промпты для ИИ
В рамках задания ИИ использовался для подготовки описаний эндпоинтов, моделей данных и ошибок.
1. Промпт для описания эндпоинтов
Ты — разработчик FastAPI. Сформулируй краткие и точные описания для эндпоинтов минимального Task Manager API:
POST /tasks — создание новой задачи.
GET /tasks/{task_id} — получение задачи по её идентификатору.
Описания должны быть понятными и подходить для отображения в Swagger UI. Не добавляй функциональность, которой нет в API.
2. Промпт для описания моделей данных
Ты — разработчик FastAPI. Сформулируй краткие и точные описания для моделей данных TaskCreate и Task.
TaskCreate содержит:
- title — название задачи, строка от 3 до 100 символов;
- description — необязательное описание задачи;
- priority — приоритет задачи, целое число от 1 до 5.
Task содержит те же поля и дополнительно:
- id — уникальный идентификатор задачи.
Описания должны быть понятными и подходить для отображения в Swagger UI.
3. Промпт для формулировки ошибок
Ты — разработчик FastAPI. Сформулируй краткие и понятные описания ошибок для минимального Task Manager API.
Необходимо описать следующие ошибки:
- 404 — задача с указанным идентификатором не найдена;
- 422 — переданы некорректные данные или параметры.
Формулировки должны соответствовать фактическому поведению API и подходить для отображения в Swagger UI.

## Использование результатов ИИ
Полученные с помощью ИИ описания были проверены вручную и скорректированы с учётом фактической реализации API.
Результаты добавлены в код FastAPI:

- Field(description=...) используется для описания полей моделей данных;
- responses используется для описания ошибок.
После внесения описаний результат был проверен в Swagger UI.
